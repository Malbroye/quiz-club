# QUIZ

- Pour les demandes de récupération d’images web, privilégier [Scrapling](https://github.com/d4vinci/Scrapling). L’import est intégré au projet et se lance avec `npm run media:scrape`.
- Prendre les URL dans le catalogue des images et conserver le chemin `media.file` sous `public/media/`. Utiliser un dossier par sujet et préserver les fichiers déjà présents.
- Après un import, vérifier les fichiers effectivement enregistrés et signaler les images manquantes ou les sources inaccessibles.
